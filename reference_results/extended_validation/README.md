# Extended validation and sensitivity reference results

These compact CSVs are successful-run outputs used to verify the extended validation and sensitivity analyses in repository v1.0.0.

They cover:
- hourly Arrhenius integration and equivalent-damage-temperature diagnostics;
- meteorological temporal coincidence;
- hourly versus daily climate-energy-index validation;
- monthly hourly calibration factors;
- propagated original versus hourly-calibrated AF/lifetime/GWP summaries;
- heatwave/non-heatwave stress decomposition and counterfactual service life;
- grid-cell/bilinear/regional spatial heatwave sensitivity;
- rsds and wind change diagnostics;
- factorial structural uncertainty envelopes.

These files retain computational precision for traceability. Manuscript reporting should use uncertainty-aware significant figures.

Large daily/intermediate files are intentionally excluded from Git.
